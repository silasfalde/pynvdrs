# Changelog

## 0.1.0

Initial public release of `pynvdrs`.

- Added reusable path helpers with environment-variable overrides.
- Added NVDRS text cleanup and optional SymSpell spelling correction.
- Added annotation disagreement, IAA, and model comparison helpers.
- Added demographics loading and transformation helpers.
- Added a lightweight GPT client wrapper with response parsing utilities.
- Added packaging metadata, optional extras, CI, and release automation.
